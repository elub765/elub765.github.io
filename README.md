# Evan Lubarsky — Mechanical Engineering Portfolio

Static copy of https://evanlubarsky.framer.website, published from the root of `main` at https://elub765.github.io.

## Pages

- `/`: introduction, selected projects, and current focus
- `/face-tracking-phone-mount/`: Tracy 1.0 project
- `/autonomous-over-terrain-vehicle/`: engineering design course project
- `/contact/`: contact details, résumé preview, and original PDF download link

The pages are ordinary HTML with one shared stylesheet. No build step, JavaScript framework, or Framer runtime is required. `.nojekyll` enables direct static serving on GitHub Pages. Configure Pages to deploy from `main`, `/ (root)` if it is not already enabled.

## Editing

Edit the appropriate `index.html` for content and `assets/styles.css` for the design. Fonts are stored locally in `assets/fonts/`. Links use the root path because this is the account's GitHub Pages repository.

The portrait, CAD, video, and phone-project gallery placeholders intentionally reproduce what was visible on the source site on October 7, 2026. No project images or videos were present in the inspected pages. The résumé retains the source Google Docs preview and PDF export links; their availability depends on the document's sharing settings.

Desktop spacing, typography, colors, and content follow the original. Smaller screens use stacked layouts to avoid the source site's clipped navigation and columns. Project-card hover motion and smooth anchor scrolling respect reduced-motion preferences.
