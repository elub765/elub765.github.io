# Original portfolio fonts

Archivo (regular and semibold) and Technor (semibold and bold) are the Fontshare fonts used by the source Framer site. These files were copied from the font URLs observed in the rendered source, so the static portfolio can serve the same typography without the Framer runtime.

Original font providers: https://www.fontshare.com/fonts/archivo and https://www.fontshare.com/fonts/technor.
